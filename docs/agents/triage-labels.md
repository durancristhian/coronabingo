# Triage labels

Use these values in each ticket's `Status:` field.

| Role | Value | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Needs maintainer evaluation |
| needs-info | needs-info | Waiting for more information |
| ready-for-agent | ready-for-agent | Fully specified and ready for an agent |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be pursued |

When a skill names a triage role, use the corresponding value above.
Execution progress is tracked separately, as described in `issue-tracker.md`.
